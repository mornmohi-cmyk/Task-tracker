# Task Tracker (C# Console)

A console task manager with JSON persistence. Built entirely on a phone.

## Features
- Add, list, and complete tasks
- Saves to `tasks.json` — data persists after closing
- Corrupted-file recovery (auto-resets broken JSON)
- Input validation and error handling
- Human-readable output with status indicators

## Tech
C#, .NET, System.Text.Json

## Purpose
Self-taught portfolio project practicing OOP, file I/O, serialization, and exception handling.
